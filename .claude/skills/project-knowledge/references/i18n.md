# i18n

### A new key in `messages.properties` must be added to every `messages_xx.properties` file (except `messages_en`), in English when there is no translation
- Why: `system/I18nPropertiesSyncTest.checkI18nPropertyFilesAreInSync` fails the build when a key is missing from any language file. Spring would fall back to English silently, but the build would not.
- Example: `src/main/resources/messages/messages_de.properties:10` (`duplicate.visitDate`, in English).
- Source: PET-101, failed check (step 6) and developer's answer 7.
